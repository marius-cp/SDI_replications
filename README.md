### Replication Material

This repository contains the replication material for the paper
**Statistical Inference for Score Decompositions**.  
The replication material relies on the R package **SDI**, which is
available at  
<https://github.com/marius-cp/SDI>.

The material is organized into the following main folders:

- **00_functions**  
  Contains reusable R functions and helper scripts that serve as
  building blocks for the simulations and applications.

- **01_simulation**  
  Implements the simulation experiments, generates results, and provides
  code for their analysis.

- **02_application**  
  Includes scripts for the the empirical applications.
